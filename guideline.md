## Implementation Order

The phases MUST be implemented in this exact order. Each phase depends on the previous ones.

```
Phase 01  ──>  Phase 02  ──>  Phase 03  ──>  Phase 04  ──>  Phase 05  ──>  Phase 06
  Setup        Auth/Users     Catalog       Inventory     Suppliers/     Purchases
                                                         Customers
    │                                                              │
    │              ┌───────────────────────────────────────────────┘
    │              │
    v              v
Phase 07  ──>  Phase 08  ──>  Phase 09  ──>  Phase 10  ──>  Phase 11  ──>  Phase 12
  Sales/POS    Dashboard/     Notifications  Audit/        Multi-Branch   Testing/
               Reports        Auto-Reorder   Settings                     Deployment
```

### Why This Order

| Phase | Depends On | Reason |
|-------|-----------|--------|
| 01 - Project Setup | None | Foundation: DB, config, layout |
| 02 - Auth & Users | Phase 01 | Needs DB + config for sessions |
| 03 - Catalog | Phase 01 | Needs DB schema for products/categories |
| 04 - Inventory | Phase 03 | Needs products + branches to track stock |
| 05 - Suppliers/Customers | Phase 01 | Needs DB, benefits from auth for access control |
| 06 - Purchases | Phase 03, 04, 05 | Needs products, inventory, and suppliers |
| 07 - Sales/POS | Phase 03, 04 | Needs products and inventory for stock deduction |
| 08 - Dashboard/Reports | Phase 06, 07 | Needs sales and purchase data to display |
| 09 - Notifications | Phase 04, 06 | Needs inventory + purchases for low stock / due alerts |
| 10 - Audit & Settings | Phase 02+ | Needs activity logging from all modules |
| 11 - Multi-Branch | Phase 04, 08 | Needs inventory + dashboard for branch views |
| 12 - Testing & Deploy | All above | Tests and docs for the full system |

## Notes for Future AI Sessions

- This project uses **PHP 8 + MySQL 8 + Vanilla JS + Bootstrap 5 + Chart.js**
- No framework (Laravel, etc.) - pure PHP with a simple class-based architecture
- Each class maps to a DB table and handles its own CRUD
- API endpoints return JSON via `jsonSuccess()` / `jsonError()` helpers
- Frontend pages use `apiRequest()` JS helper for AJAX calls
- All destructive actions (delete) are logged in `activity_logs` table
- The "wow factor" is the **auto-reorder system** in Phase 09
